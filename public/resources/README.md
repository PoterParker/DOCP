# DOCP 项目资源目录

网站资源按内容用途归档。项目素材请放入对应案例的 `图片`、`视频` 或 `文档` 文件夹中。

## 目录结构

- `个人资料`
  - `头像`：个人头像与形象照片
  - `简历`：公开版简历及附件
  - `联系方式`：二维码等联系素材
- `运营活动`
  - `盛夏巡游季`
  - `周年庆典计划`
  - `归航者计划`
- `系统玩法`
  - `共创公会系统`
  - `装备构筑实验室`
  - `伙伴羁绊网络`
- `其他`
  - `无字新手引导`
  - `战斗可访问性套件`
  - `游戏交互规范库`

## 建议命名

- 图片：`封面-01.webp`、`界面-01.webp`
- 视频：`交互演示-01.mp4`
- 文档：`项目说明.pdf`、`流程图.pdf`

替换各目录中的 `.gitkeep` 占位文件后，即可正常提交真实素材。
